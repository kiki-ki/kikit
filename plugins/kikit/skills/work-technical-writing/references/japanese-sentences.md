# 日本語の文の規則

日本語に固有の規則だけを書く。言語によらない文の規則は、SKILL.md の「3. 文を書く」にある。

## 文の長さと構造

- 一文は 80 字、読点は 3 つまでを目安にする
- 逆接でない「が」で文をつながない。「A だが、B」は A と B が対立するときだけ使う
- 主語と述語を近づける。長い修飾語は前に、短い修飾語は後ろに置く
- 修飾語の係り先が二通りに読める語順を避ける。「〜ない」「〜だけ」は、係る語の直前に置く
- 同じ助詞を 1 文の中で続けない（「A の B の C の」など）
- 短い主題（「〜は」「〜が」「〜を」）の直後に、間を作るだけの読点を打たない。「作業の結果は、本物を見る」は「作業の結果は本物を見る」と書く。主題のあとに別の動作主が続くときと、外すと係り先が変わるときは残す
- 否定対比を 2 文に分けない。「A しない。B する。」は、否定を残して「A せずに B する」の 1 文にする

## 冗長な言い回し

- 「〜することができる」→「〜できる」
- 「〜を行う」「〜を実施する」→「〜する」
- 「〜という形で」「〜という点で」「〜的な」→ 削るか、具体的に言う
- 「〜していく」「〜してまいります」→「〜する」
- 丁寧さを均一に積み上げない（「〜させていただきます」の連続）
- 体言止めで、何が起きるかを言わずに文を終えない

## 主語と語

- 文脈から明らかな主語（「私たちは」「このシステムは」）を毎文書かない
- 「これ」「それ」「この」「その」は、指す先が直前の文にあり、一読で一つに決まるときだけ使う。段落や見出しをまたいで指さない。指す先の候補が二つ以上あれば、名詞を繰り返す
- 日本語の言い方が定着しているものは、カタカナ語で書かない。「エビデンス」は「根拠」、「アジェンダ」は「議題」と書く

## 括弧

- 丸括弧は、略語の正式名、例、値のような短い補足だけに使う。1 文に 1 つまでにし、括弧の中に文を書かない。中身が文になるなら、括弧から出して別の文にする
- 同じ意味を言い直すだけの括弧は削る。「AI 臭さ（不自然な日本語）」は「AI 特有の不自然な日本語」と書く
- 手順や依頼を括弧に入れない。「設定を編集する（先にバックアップを取る）」は「先にバックアップを取り、設定を編集する」と、行う順に書く
- 強調のためだけにかぎ括弧で囲まない。かぎ括弧は、引用、用語の定義、画面の項目名に使う

## 文体と表記

- 敬体と常体は、書き足す先の文書がどちらかに決まっていればそれに合わせ、なければ常体にする。1 つの文書の中で混ぜない
- 英数字と日本語の間に半角スペースを入れる
- 句読点は「、」「。」。感嘆符と疑問符は使わない
- 箇条書きの項目の末尾には「。」を付けない。項目の中に文が複数あるときも、途中の文だけを「。」で区切る
- 形式名詞と補助動詞はひらがなで書く（こと・とき・もの・ところ・ください・いる・みるなど）
- 数は算用数字で書く。「一つ」「一度」のように、数えていない慣用表現は漢数字のままにする
- ダッシュ（——）を地の文で使わない。補足は文を分けて書く
- スラッシュで「A/B」とまとめない。「A と B」「A または B」と書く
